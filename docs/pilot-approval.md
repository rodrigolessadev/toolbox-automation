## Limites da aprovação

Esta aprovação autoriza somente:

- análise;
- implementação local dentro do escopo;
- execução de validações previstas;
- atualização dos registros da automação.

Esta aprovação não autoriza:

- `git push`;
- pull request;
- merge;
- release;
- deploy;
- publicação de pacote;
- descarte de alterações;
- acesso a dados sensíveis;
- instalação de dependências;
- alterações fora do escopo.

## Expiração

A aprovação deverá ser considerada expirada quando:

- o escopo mudar;
- outro repositório for incluído;
- o risco aumentar;
- surgir uma dependência;
- ocorrer uma alteração inesperada;
- houver interrupção com mudança de estado;
- forem necessárias ações externas.
