# MCP de documentação

## Identificação

- Nome conceitual: `documentation`
- Categoria: documentação e referências técnicas
- Nível padrão: 1
- Acesso externo: depende da fonte consultada

## Objetivo

Consultar documentação técnica para compreender APIs, runtimes, frameworks,
formatos, ferramentas e contratos utilizados pelos projetos.

## Fontes permitidas

- documentação mantida nos repositórios;
- documentação oficial de ferramentas;
- especificações públicas;
- documentação oficial de dependências;
- referências aprovadas pelo projeto.

## Operações permitidas

- pesquisar documentação;
- consultar versões;
- verificar compatibilidade;
- comparar APIs;
- localizar instruções oficiais;
- registrar referências;
- produzir resumo técnico.

## Operações não permitidas

- enviar código proprietário sem aprovação;
- enviar segredos;
- enviar dados pessoais;
- enviar arquivos completos para serviços externos;
- tratar documentação não oficial como fonte definitiva;
- instalar dependências apenas com base em uma sugestão não verificada.

## Agentes autorizados

Todos os agentes podem consultar documentação, desde que:

- a consulta seja pertinente à tarefa;
- nenhum dado sensível seja enviado;
- a fonte seja registrada quando a informação afetar uma decisão.

## Regra para fontes externas

Quando a documentação externa for necessária:

- registrar a URL;
- registrar a data de consulta;
- confirmar a versão;
- diferenciar fato documentado de interpretação;
- não copiar credenciais ou conteúdo sensível.

## Indisponibilidade

Se a documentação não puder ser consultada:

- registrar a limitação;
- não inventar o comportamento;
- marcar a informação como `A confirmar`;
- bloquear quando a decisão depender dessa informação.
